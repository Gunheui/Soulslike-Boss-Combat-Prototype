## 1. 핵심 전투 루프 (한 문단)

보스가 **읽을 수 있는 텔레그래프**로 공격을 시작한다 → 플레이어는 도망치는 대신 **제자리에서 정확한 타이밍에 막는다(퍼펙트가드)**. 퍼펙트가드는 칩 데미지 0, 가드게이지 소모 0, 그리고 **적 스태거 게이지를 크게 적립**한다(회피로는 스태거가 안 쌓인다 — 이게 핵심 trade-off). 콤보 스트링의 각 타를 연속으로 퍼펙트가드하며 버티면 → **펀시 윈도우**가 열린다 → 플레이어가 약/강공격으로 반격해 추가 스태거를 쌓고, 막다 잃은 회색 체력을 **가드 리제너레이션**으로 회복한다 → 스태거 게이지가 만탱하면 보스가 **그로기** 상태로 무너진다 → 플레이어가 **치명타**로 큰 데미지를 박는다. 즉 이 게임의 전투는 "거리를 벌리는 인내"가 아니라 **"버티며 받아쳐 무너뜨리는 공격적 방어"**다. 회피는 가드불가(잡기·적색) 공격에만 강제되는 비상 탈출구이지, 주력 동사가 아니다.

## 2. 플레이어 동사(Verb) 표

| 동사 | 설명 | 핵심 파라미터 (출발값 — 상세는 feel-params) |
|------|------|---------------------------------------------|
| **이동** | 락온 기준 8방향 이동, 락온 중 스트레이프 | 보행 2.5 m/s, 락온 스트레이프 2.0 m/s, 회전 720°/s |
| **달리기** | 스태미나 소모 이동, 거리 조절·패턴 회피 | 달리기 5.0 m/s, 스태미나 -8/s |
| **회피(스텝)** | 짧은 스텝 + i-frame. **가드불가 전용 비상 동사** | i-frame 3f후 시작·11f 지속(0.18s), 거리 3.5m, 후딜 9f, 스태미나 -25 |
| **약공격** | 빠른 2~3타 콤보. 펀시 윈도우 주력 딜 | 모션 24f, 데미지 18, 스태거 +8/타, 스태미나 -16 |
| **강공격(차지)** | 느린 고데미지, 차지 가능. 그로기 굳히기·스태거 굳히기 | 모션 45f(차지 75f), 데미지 40(차지 70), 스태거 +20(차지 +38), 스태미나 -30 |
| **일반가드** | 막기. 칩 데미지 + 가드게이지 소모. PG 실패 시 안전망 | 칩 18%, 가드게이지 -(포이즈 비례), 후딜 6f |
| **퍼펙트가드(PG)** | **정체성의 핵심.** 가드 입력 직후 좁은 윈도우 내 피격 시 성립 | 윈도우 8f(0.13s), 칩 0, 가드게이지 0, **적 스태거 +18**, 적 미세경직 6f |
| **가드 리제너레이션** | 가드/PG로 잃은 체력을 회색으로 보존, 반격 명중 시 회복 | 회색 유지 5s, 공격 1회당 잃은 양의 35% 회복 |
| **치명타(크리티컬)** | 그로기 상태 적에게 큰 일격 + 무적 연출 | 데미지 150(고정), 연출 1.5s 무적, 거리 2.5m 내 입력 |

> **설계 의도:** 회피의 i-frame(11f)을 PG 윈도우(8f)보다 길게 두되, 회피는 **스태거 0 / 거리만 확보 / 후딜 김(9f)**으로 "안전하지만 이득 없음"에 묶는다. PG는 **윈도우는 좁지만 스태거+체력회복기회+적 경직**으로 "위험하지만 압도적 이득". 이 비대칭이 정체성을 만든다.

## 3. 핵심 메커니즘 서술

### 3.1 퍼펙트가드 (Perfect Guard) — 정체성의 핵심

- **작동 방식:** 가드 버튼을 **적 공격이 닿기 직전에** 누른다. 가드 입력 시작 후 **8f(0.13s @60fps)** 이내에 피격 판정이 들어오면 "퍼펙트가드" 성립. 시간 기반 윈도우(프레임 입력보다 관대·튜닝 쉬움).
- **보상 (회피보다 매력적이어야 함 — 정체성 핵심):**
  1. 받는 데미지 **0** (일반가드는 칩 18%).
  2. 가드게이지 소모 **0** (일반가드는 포이즈만큼 소모 → 가드브레이크 위험 누적).
  3. **적 스태거 게이지 +18 적립** ← **회피로는 0. 이게 PG를 주력으로 만드는 단 하나의 이유.**
  4. 적에게 **미세 경직 6f** → 콤보 스트링 중 PG 연속 성공 시 보스 콤보를 끊고 펀시 윈도우를 앞당김.
- **리스크:** 윈도우가 좁다(8f). 늦으면 일반가드(칩 18% + 게이지 소모), 너무 늦으면 그냥 피격(풀 데미지). 즉 **욕심내면 처벌**.
- **밸런스 레버:** 윈도우 폭(8f, 0순위 튜닝값)과 스태거 적립량(+18)이 난이도·정체성의 80%.

### 3.2 스태거 / 그로기 (Stagger / Groggy)

- **충전:** 퍼펙트가드(+18), 강공격(+20, 차지 +38), 약공격(+8/타), 치명타 가능 상황 등이 보스 스태거 게이지(최대 100)를 채운다.
- **감소:** 마지막 적립 후 **1.5s 지연** → 이후 **12/s로 감소**(공세 유지 압박 — 손 놓으면 게이지가 녹는다). 감소율이 리듬을 좌우.
- **발동:** 게이지 만탱 → 보스 **그로기**(흰색 점멸 + 무릎 꿇음 신호) → 치명타 입력 윈도우 **4s** 오픈.
- **보상/리스크:** 스태거를 쌓으려면 도망 대신 **PG로 버티고 펀시 윈도우에 반격**해야 한다. 즉 시스템 자체가 공격적 방어를 강제한다.

### 3.3 치명타 (Fatal / Critical Attack)

- **트리거(MVP):** 스태거 게이지 만탱 → 그로기 → 보스 2.5m 내 접근 + 치명타 입력. (P의 거짓의 "충전 강공격 그로기·무기파괴 트리거"는 Backlog.)
- **보상:** 고정 **150 데미지**(또는 최대HP의 12%) + 연출 중 **플레이어 무적 1.5s**(2페이즈 난전에서 숨 돌릴 안전구간 겸 보상).
- **리스크:** 그로기 윈도우(4s) 내 접근 실패 시 기회 소멸. 보스 1페이즈/2페이즈 전환 직전 그로기는 페이즈 무적과 충돌하지 않게 처리 필요(→ architect 확인 포인트).

### 3.4 가드 리제너레이션 (Guard Regain / Rally)

- **작동 방식:** 가드·일반가드 칩으로 잃은 체력이 즉시 사라지지 않고 **회색(회복 가능) 영역**으로 남는다. **5s 내** 보스에게 공격을 명중시키면 회색의 **35%/타** 회복.
- **효과:** "막고 → 받아치면 손해가 0에 수렴"이라는 P의 거짓 랠리 철학. PG는 애초에 칩 0이지만, 일반가드로 새는 칩을 펀시 윈도우 반격으로 메우는 보조 루프. 방어를 더 공격적으로 만든다.
- **리스크:** 회색은 5s 지나면 소멸. 보스 공격에 또 맞으면 회색째로 깎임(회복 기회 상실).

## 4. 자원 시스템 표

| 자원 | 최대치 | 소모 | 회복 | 임계값/특이 |
|------|--------|------|------|-------------|
| **HP** | 100 | 피격 시 감소 / 일반가드 칩(18%) | 가드 리제너레이션(회색 35%/타, 5s 유지) | 0 = 사망. PG는 소모 0 |
| **스태미나** | 120 | 회피 -25 / 약공 -16 / 강공 -30 / 달리기 -8/s / 일반가드 피격 -(포이즈 비례) | 비행동 1.0s 후 40/s | 0 = 회피·공격 불가(가드는 가능, 탈진). PG 입력 자체는 스태미나 0 — 단 PG **실패→일반가드** 시 소모 |
| **가드게이지** | 100 | 일반가드 피격 시 포이즈 비례 소모 / **PG는 0** | 비가드 2.0s 후 20/s | 0 = 가드브레이크(경직 30f, 강제 피격). PG로만 막으면 게이지가 안 줄어 무한 방어 가능 → PG 숙련 보상 |
| **(보스)스태거** | 100 | — | 마지막 적립 1.5s 후 12/s 감소 | 만탱 = 그로기 4s → 치명타 |

> **자원 간 상호작용 의도:** PG는 스태미나·가드게이지·HP를 **전혀 안 쓰면서** 스태거만 쌓는다 → 숙련자에겐 거의 무자원 공격적 방어. 일반가드/회피는 자원을 쓴다 → 미숙할수록 자원 압박. "잘하면 자원이 안 든다"는 숙련 곡선이 정체성을 강화.
