## 1. 보스 컨셉 (한 줄)

**「그을린 파수병(The Cinder Sentinel)」** — 폐허가 된 성문을 지키는 거대한 갑주 기사. 한 손엔 묵직한 대검, 다른 손엔 깨진 방패. 느리고 묵직한 1페이즈에서, 갑주가 균열되며 검에 불이 붙는 2페이즈로 전환되어 빠르고 공격적인 연계로 변모한다. **테마: 무게 → 화염. 인내 → 광분.**

> 단일 무기(대검) 기반의 읽기 쉬운 텔레그래프 + 묵직한 박자 → 퍼펙트가드 학습에 이상적인 "교과서형 보스".

## 2. 공격 패턴 표

> **펀시 윈도우** = 공격 종료 후 플레이어가 안전하게 반격 가능한 프레임(약공 2타 ≈ 48f 기준).

### 패턴 상세 메모

- **#2 내려찍기 (바이트 베이트, 필수 1개 ✔):** 텔레그래프 후 검을 머리 위에 **10f 멈췄다가** 친다. 텔레그래프(28f)에 반응해 성급히 PG/회피하면 윈도우가 끝나 처벌. **늦게** 막아야 PG 성립 → 학습 곡선 핵심. 명중 시 12f 경직으로 추가 처벌. 펀시 윈도우는 길어(42f) 인내 보상.
- **#3 방패 밀치기:** 데미지는 낮지만 **포이즈 24**로 일반가드 시 가드게이지를 크게 깎는다 → "일반가드로 버티면 가드브레이크" 압박 → PG 강제. PG 중심 정체성을 시스템으로 강요하는 패턴.
- **#4 돌진 베기:** 유일하게 **회피가 PG보다 합리적**인 패턴(거리·각도상). 동사 다양성 확보 — PG 일변도 방지. 단 정면 PG도 가능하게 열어둠(고위험 고보상).
- **#6 포박 잡기 (가드불가, 필수 1개 ✔):** **적색 점멸 + 전용 SFX**로 가드불가 명시. 가드(일반/PG) 무시하고 잡아 50 데미지 + 90f 다운. **회피만** 정답. 2페이즈 주력이나, 1페이즈 HP 60% 지점에서 **1회 예고 등장**(학습용). 빗나가면 큰 펀시(36f).
- **#7 화염 사선베기 (2페이즈):** PG 성공 시 화상 DoT까지 무효 → PG가 단순 방어를 넘어 "상태이상 차단"으로 가치 상승. 일반가드는 칩 + 화상 둘 다 받음.
- **#8 광분 4연타 (2페이즈):** 1페이즈 #5(3연)의 강화판. 타당 14f로 빠르고 4타 → 연속 PG 4회 요구. 후반 숙련 시험. 풀 PG 시 스태거 +72(콤보 하나로 그로기 근접) → 숙련 보상 극대화.

## 3. 페이즈 전환 명세

### 전환 조건 · 연출
- **트리거:** 보스 HP **50% (600/1200)** 도달.
- **무적 연출:** 전환 시작 시 보스 **1.5s 완전 무적 + 슈퍼아머**(플레이어 공격 무시·경직 없음). 갑주 균열 → 검 발화 연출. 이 1.5s 동안 플레이어 공격은 통과(데미지 0)되며, 보스는 후퇴(2m) 후 포효.
- **엣지케이스 (→ architect 확인):** 전환 직전 보스가 **그로기 상태**이거나 **치명타 연출 중**이면? → 규칙: **그로기/치명타 연출이 우선 완료된 뒤** HP 50% 체크 → 전환. 치명타 데미지로 HP가 50% 아래로 내려가도 연출 종료 후 전환 진입. (그로기 중 전환 무적 진입 금지 — 치명타 보상 박탈 방지.)
- **스태거 처리:** 전환 시 보스 스태거 게이지 **0 리셋**.

### 2페이즈 변화 (속도 / 신규 패턴 / 콤보 연장)

| 변화 축 | 1페이즈 | 2페이즈 |
|---------|---------|---------|
| **신규 패턴** | #1~#5 (#6은 60% 예고 1회) | **#6 포박 상시 / #7 화염 사선 / #8 광분 4연타 추가** |
| **공격 속도** | 기준 | 텔레그래프 **-15%**(약 0.85배), 판정 동일 → PG 윈도우 체감 압박 ↑ |
| **콤보 연장** | #5 = 3타 | #8 = 4타 + 일부 패턴 **콤보 연계**(예: #1 횡베기 → #7 화염 사선 캔슬 연결) |
| **공세 빈도** | 공격 후 평균 대기 1.2s | 평균 대기 **0.8s** (펀시 윈도우는 표값 유지 — 욕심 처벌 강화) |
| **화염 부가** | 없음 | #7 화상 DoT, 일부 베기 잔상 판정 6f 추가 // 튜닝 필요 |
| **체력** | 600 | 600 (합 1200) |

> **2페이즈 설계 의도:** "더 빠르게"를 텔레그래프 단축(-15%)으로 표현 → **PG 윈도우(8f) 절대값은 그대로**지만 보스 모션이 빨라져 체감 난이도가 오른다. 신규 패턴(가드불가 상시화·화염·4연타)이 PG·회피의 **읽기 부담**을 늘린다. 콤보 연장·연계는 "연속 PG 성공 → 큰 스태거 → 그로기 → 치명타"의 보상 루프를 후반에 더 짜릿하게 만든다.

## 4. 한 판 흐름 가설 (검증용 시나리오)

> QA가 "의도대로 플레이되는가" 검증할 때의 기대 시나리오.

1. 1페이즈: #1·#3·#5 위주. 플레이어가 PG로 스태거 적립 → **그로기 2~3회 → 치명타** → HP 50% 도달.
2. 60% 지점 #6 포박 1회 예고로 "가드불가 = 회피" 학습.
3. 전환(무적 1.5s) → 2페이즈.
4. 2페이즈: #6 상시 위협 속에서 #7·#8를 PG로 받아내며 그로기 **2~3회 추가 → 치명타** → 격파.
5. **목표 지표:** 한 판당 그로기 4~6회, 치명타 4~6회, 평균 클리어 3~6분, PG 성공률 숙련 시 60%+. (QA 측정 대상.)
