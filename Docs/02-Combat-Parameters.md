## 튜닝 우선순위 (QA / 플레이테스트용)

1. **퍼펙트가드 윈도우 8f** — 너무 좁으면 좌절, 너무 넓으면 정체성 붕괴.
2. **스태거 감소율 12/s** — 그로기 도달 빈도 결정. 한 보스전당 그로기 3~5회 목표.
3. **PG 스태거 적립 +18** — 한 콤보 스트링(3~4타) PG로 그로기 절반 이상 차야 손맛.
4. **회피 i-frame 11f vs 보스 판정 6~10f** — i-frame이 모든 판정을 덮으면 회피 남용 → 정체성 훼손. 일부 판정은 i-frame보다 길게(딜레이드 어택).
